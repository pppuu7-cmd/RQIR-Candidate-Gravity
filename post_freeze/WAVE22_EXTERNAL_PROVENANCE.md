# Wave 22 external physics provenance

Wave 22 uses external literature only to motivate which *classes of observables* belong in a future blind QGR test bank; it does not import numerical Wilson coefficients or model-specific fits.

- Z. Bern, D. Kosmopoulos, A. Zhiboedov, **Gravitational Effective Field Theory Islands, Low-Spin Dominance, and the Four-Graviton Amplitude**, arXiv:2103.12728. Relevance: an `R^3` operator modifies the graviton three-point amplitude while four-graviton unitarity/crossing data constrain it in relation to higher-order EFT information. This motivates explicit cross-order 3pt/4pt holdouts.
- J. Calderón-Infante, A. Castellano, A. Herráez, **The Double EFT Expansion in Quantum Gravity**, arXiv:2501.14880. Relevance: quantum-gravity EFTs can contain structured higher-curvature expansions governed by more than one physical scale, motivating a holdout bank that does not assume all higher-order coefficients are functions of one lower-order parameter.

Claim boundary: these references support the need for cross-order/higher-curvature observables; they do not establish the specific finite proxy sensitivity matrix used in Wave 22.
