## Question

Does upgrading from response/kernel constraints to **one explicit action-level parameter space**, while quotienting redundancies and adding Ward, higher-point amplitude bounds, UV-gap information and minimum-complexity discipline, uniquely determine the physical higher-order gravitational couplings?

If not, frozen RQIR-only reconstruction has reached a quantified action-level equivalence-class endpoint in the declared finite proxies.

## Predeclared tests

1. **Single-action rank:** put two-point and cubic Wilson directions in one parameter vector and test whether two-point information fixes the cubic directions merely because they belong to the same action.
2. **Field-redefinition quotient:** remove EOM/redefinition-redundant coordinates and test whether physical cubic directions remain.
3. **Background/nonlinear Ward rank:** measure whether action-level Ward identities fix transverse higher-order coefficients or only gauge/longitudinal combinations.
4. **Four-point bound:** use a dimensionless inequality proxy `c3^2 <= c4` to test the logical difference between an amplitude bound and unique coefficient determination. No published numerical coefficient is imported.
5. **Minimum-complexity selector:** test whether the RQIR simplicity objective chooses a representative even when physics leaves a family, and explicitly prevent that choice from being mislabeled a law.
6. **UV-gap selector:** use the parametric proxy `|c3| <= Delta_gap^-2` to test whether UV-completion information determines a coefficient or trades low-energy freedom for UV-spectrum data.
7. **Endpoint witness:** construct two one-action witnesses with the same selected lower-order/Ward/soft/admissibility information but different finite three-point predictions.
8. **Comparator firewall.**

## Fail-closed endpoint criterion

An RQIR-only unique microscopic reconstruction is supported only if all physical higher-order directions are removed by independently justified physics. Redundancy removal, inequality bounds, and a minimum-complexity convention do not count as physical determination.

If an explicit physical cubic direction survives all tested RQIR/consistency/admissibility information, the appropriate result is an **equivalence class / no-go for uniqueness within scope**, not a failed search to be repaired by adding an outcome-selected postulate.
