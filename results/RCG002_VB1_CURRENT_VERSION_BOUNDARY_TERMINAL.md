`J(a,b,c)=J0+a A+b B+c C`, with `a,b,c in {0,1}`.

`W2[J] = C + L[J] + (1/2) B[J,J]`,

`Delta_A Delta_B Delta_C W2[J(a,b,c)] = 0`
