# RQIR-Candidate-Gravity

Independent candidate-gravity model derived from the frozen RQIR reconstruction requirements.

## Research rule

This repository deliberately does **not** use the structure, equations, or patches of the QGR candidate being developed from the benchmark/polygon route. Its purpose is to test whether the original RQIR funnel independently constrains a viable gravity–quantum interface model.

## Construction path

RQIR requirements → formal constraints → minimal degrees of freedom → admissible dynamics → observable map → frozen validation → holdout tests.

The model is not to be fitted by changing the RQIR gates after construction.
